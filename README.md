# axisdtf-site

Static site for axisdtf.com, the Axis Enterprises garment printing brand: DTF printers, TPU label printing, digital embroidery and flocking.

Deployed to Hostinger public_html. Everything in this repo is generated by build.py, so edit the generator, never the HTML.

Structure: 9 pages plus blog/, assets/, llms.txt, robots.txt, sitemap.xml, .htaccess and send-enquiry.php.
